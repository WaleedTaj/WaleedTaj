**Tech:** Flutter, Dart

### ❤️ BloodSync — Blood Donor Connectivity

A mobile application designed to help connect voluntary blood donors with people seeking blood donations.

**Key Features:** Blood requests, donor registration, nearby donor discovery, location-based features, and notifications.

**Tech:** Flutter, Dart, Google Maps
